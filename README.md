# Job Tracker Pro

A beautiful, full-featured job application tracker to help you land your dream job.

## Features

- **Dashboard** - See your job search progress at a glance with animated stats
- **My Jobs** - Kanban board to track jobs through Applied, Talking, Offer, and Not Moving Forward stages
- **Analytics** - Charts showing your application trends, response rates, and success metrics
- **Interview Prep** - Practice questions, mock interview timer, and salary comparison tool
- **My Network** - Track contacts and connection follow-ups with message templates
- **Documents** - Organize resume versions and check keyword matching against job descriptions
- **Job Scanner** - Quick-add jobs from URLs with salary estimation

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Open a terminal and navigate to the project folder

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and go to `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Tech Stack

- React 18 with TypeScript
- Vite for fast development
- Three.js for 3D animated background
- Framer Motion for smooth animations
- Recharts for analytics charts
- Tailwind CSS for styling
- Supabase for backend (database ready)
- Lucide React for icons

## Design

- Midnight dark theme (#030307)
- Cyber Violet to Electric Cyan gradient accents
- Glassmorphism cards with glowing borders
- 3D interactive particle background
- Mobile-responsive sidebar navigation
